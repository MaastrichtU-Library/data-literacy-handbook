# How to use this Handbook

1. [For Bachelor's students](../paths/BAstudent.md)
2. [For (Research) Master's students](../paths/MAstudent.md)
3. [For dealing with qualitative data](../paths/qualitative.md)
4. [For dealing with quantitative data](../paths/quantitative.md)
5. [As teaching staff](../paths/teacher.md)
6. [While working on a thesis project](../paths/thesis.md)
