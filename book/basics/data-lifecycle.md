**In research, data goes through different stages. In this framework, the process is seen as circular, as data can go through the same stages multiple times.** 

The main research data lifecycle phases can be described as follows:

* The **planning** phase, where the idea for which data to use, for which purpose, and how to treat them is defined.
* The **collection** phase, when data are directly collected or otherwise acquired.
* The **analysis and interpretation** phase, where data are processed in order to gather insights.
* The **archiving** phase, when data are appraised to see their relevance in the longer term and, where relevant, moved to long-term storage solution.
* The **publishing** phase, when the data and/or the results of the analysis are made public. 
* The **reuse** phase, where data that were published are used in a different research project.
